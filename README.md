# Анализ лояльности пользователей Яндекс Афиши

### Цель проекта
1. Провести анализ данных, чтобы понять, какие пользователи с большей вероятностью возвращаются на платформу и делают заказы повторно.

2. Трансформировать логику исследования в структурированное Python-приложение, используя принципы ООП и Git.

### Установка и запуск
 - Склонировать репозиторий: git clone git@github.com:snoskova07/analiz-loyalnosti-polzovatelej.git
 - Установить зависимости: pip install -r requirements.txt
 - Создать файл .env с параметрами подключения к БД
 - Добавить файл с данными raw_data.csv в папку /data в случае, если подключение к бд не работает
 - Добавить файл с курсом валют raw_data final_tickets_tenge_df.csv в папку /data
 - Запустить проект: python3 main.py

### Рекомендации по результатам анализа
 - Доля возврата: 61,32%
 - Фокус на сегментах: «концерты» - 61,82% , «театр» 63,44% — высокая доля и вовлечённость. В категории «другое» хороший охват, но вовлеченность ниже среднего - 59,56%.
 - Развитие мобильного канала: он приносит подавляющую часть заказов.
 - Стимулирование повторных покупок в топ‑3 регионах: там наибольший потенциал роста.
 - Опираться на медианные значения показателей, так как они точнее отражает поведение большинства.
 - Гипотезы 1 и 2 не подтвердились, сильнее всего с числом заказов связано время между заказами.
